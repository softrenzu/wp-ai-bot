# 商談即決フロー（営業用MVP）

このディレクトリは、既存のWordPress投稿ボットとは**独立した**見積・対面署名・カード継続課金アプリです。元のボットには変更を加えていません。

## 目的と出典

2026年10月16日送信「ブログ自動AI投稿サービスのお見積書・契約書案のご送付」の見積書レイアウトを参考にしました。顧客名や見積番号はその案件のものを再利用せず、都度生成します。月額15,000円（税別）+消費税10% 1,500円 = 16,500円（税込）。発行主体は**株式会社穣**（環境変数で変更可能）。

## 営業フロー

1. 営業担当者が `/admin` に管理トークン・顧客情報・個別仕様を入力し、秘密の商談URLとQRコードを発行する。顧客はその場でQRコードを読み込んで開く。
2. 顧客が商談URLから見積書と全文契約書を確認し、権限確認に同意してキャンバスへ署名する。
3. 署名日時・接続元・UA・署名画像・確定した契約書のSHA-256をPostgreSQLへ記録する。署名済みの文書は更新できない。
4. 顧客がStripe Checkoutでクレジットカードを登録し、月額サブスクリプションの初回決済を行う。
5. Stripeの署名付きWebhookで入金確定後、同じ画面から契約書・見積書・**Stripe発行**請求書／領収書へアクセスする。
6. 見積・契約書はブラウザーの「印刷・PDFとして保存」でPDF保存可能。Stripeの請求書・領収書はStripeのホスト画面にリンクする。

## セットアップ

- Node.js 20以降と PostgreSQL が必要。
- `npm install`
- `psql "$DATABASE_URL" -f schema.sql`
- `cp .env.example .env` 後、環境変数を設定する。
- `npm test`、`npm start`、`http://localhost:3000/admin` を開く。
- Stripeダッシュボードで**10%の税抜に加算する消費税率**を作成し `STRIPE_TAX_RATE_ID` に設定する。税率の自動適用は行わない。
- Webhook URL `https://your-host/webhooks/stripe` をStripeに登録する。対象イベント：
  `checkout.session.completed`、`invoice.paid`、`invoice.payment_failed`、`charge.succeeded`、`customer.subscription.deleted`。
- Stripeのメール領収書の発行設定、顧客対応用メール、事業者名と必要な税務情報をダッシュボードで設定する。
- `PUBLIC_BASE_URL` は必ず公開HTTPS URLにする。管理者トークンは24文字以上のランダム文字列を使用する。

## 確認・制約事項

**現状はソース実装段階であり、本番用Stripe資格情報・決済Webhook・DB・ドメインを接続して実決済を試した状態ではありません。** ダッシュボードでStripeアカウント設定を済ませるまでは、カード登録も請求書・領収書発行も行われません。

- 画面上の筆跡 + ログ保存は、クラウドサイン等の第三者認証型電子署名と同一の本人確認・法的推定力を保証するものではありません。対面で権限を確認し、利用規約・契約条項と証拠保全について法務レビューを実施してください。送信先メールの本人確認・OTP認証は現状未実装です。
- 契約文言は過去案件を元にした**再利用用ひな形**で、すべての顧客に無条件で適用できることを保証しません。特に保険業その他の規制業種、個人情報の国外移転、取引先独自の購買規則は個別確認が必要です。
- PDFは画面印刷により取得します。サーバー側で電子署名付きPDFを自動生成・保管する機能は未実装です。DBのバックアップ、保存期間、アクセス制御、法的な証拠保全を別途設計してください。
- Stripeの請求書・領収書の表示は実入金を示すイベントの受信後です。リンク取得に失敗した場合はStripe管理画面で確認してください。
- 適格請求書番号は未確認のため、初期値は空です。番号を確認した場合だけ `INVOICE_REGISTRATION_NUMBER` に設定してください。Stripe側の適格請求書の要件・記載も別途確認が必要です。
- OpenAI APIの支払いは本アプリでは**代行・代理課金しません**。契約画面には公式API請求設定へのリンクを表示します。顧客が `https://platform.openai.com/settings/organization/billing/overview` 等OpenAI公式画面で行います。カード番号やAPIキーを本画面で入力させないでください。
- 商談URLは秘密URLです。管理画面・URLのアクセス制御、ログの秘匿、顧客情報削除手順、CSRF/OTP/管理者認証強化、Webレート制御、脆弱性診断を本番導入前に実施してください。
- 別の料金体系・割引・月末締め翌月末払いの銀行振込条件を使う場合は、新規見積・契約書を発行してください。今回のカード決済と旧条件を混在させません。
